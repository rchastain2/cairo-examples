
# Eyes

Animated face, whose eyes follow mouse cursor. Adapted from a [LÖVE animation][1].

![Screenshot](screenshots/02.png)

## Build

```bash
cd demo
make demo CAIRO=1
```

## Build SDL2 version

```bash
cd demo-sdl
make demo CAIRO=1
```

## Play with original program

```bash
cd original
love .
```
